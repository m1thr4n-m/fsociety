Anomaly Detection Engine

A zero-server edge dashboard translating machine learning telemetry into actionable field investigations.

1. Handling Class Imbalance (LightGBM)

Because power thieves are a tiny fraction of the grid, we engineered advanced time-series features (like 7-day rolling averages and trend differentials). We then trained a LightGBM classifier with explicit balanced class weights. This mathematically penalized the model for missing rare anomalies, preventing it from getting distracted by normal seasonal variations.

2. Pinpointing Temporal Shifts (PELT)

Finding who is stealing is only half the battle. To pinpoint exactly when the theft began, we passed the highest-risk meters through a Pruned Exact Linear Time (PELT) search algorithm. This isolates the precise structural break in the consumption curve, providing a specific date to legally calculate revenue loss.

3. Scalable Edge Deployment

We decoupled the heavy ML processing from field operations. This dashboard runs entirely client-side on the inspector's local device, ensuring data privacy and zero cloud hosting costs. It parses massive CSV outputs directly in the browser, visualizing the top threats for immediate dispatch.
